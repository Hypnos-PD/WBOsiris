# 规则与素材来源契约

项目对《影之诗：超凡世界》的实现按以下来源类别使用外部资料：

| 来源 | 权威范围 | 在本项目中的用途 |
|---|---|---|
| 卡牌文本、关键词文本和 QA 文本 | 规则语义与中文游戏文本 | WBO 规则、关键词定义和测试预期 |
| 游戏原始资源包 | 贴图、字体、动画和资源 ID | 素材提取与资源格式 |
| 卡牌制作素材规范 | 卡框、图层和素材组合 | 网页端卡牌展示 |
| 可执行对局模型 | 状态、动作和结算流程 | 模拟器实现的交叉参考 |
| 效果展示工程 | 制卡交互和演示表现 | 网页端交互参考 |

## 冲突处理

1. 卡牌规则含义以卡牌文本、关键词文本和 QA 文本为准。
2. 可执行模型和效果展示只能用于发现行为假设，不能覆盖规则文本；发现冲突时应在 WBO 测试中记录并以文本为准。
3. 素材来源只决定资源与呈现方式，不决定规则语义。
4. 无法从权威文本确定的行为必须保留为未支持动作或显式诊断，不能由客户端、动画或模拟器自行猜测。

## 导入边界

卡牌导入工具的第三个参数可以传入逗号分隔的卡包 ID；省略时使用当前基础卡包。
例如传入 `10002,10003` 会增量生成这两个卡包的身份与文本骨架。
导入时数据类型按 `1=follower`、`2=amulet`、`3=spell` 映射为 WBO 的 `type`。

已有卡牌骨架也必须与当前权威数据核对类型。法术的即时效果写在 `effect` 最外层，
只有文本明确包含入场曲的随从或护符才使用 `fanfare`；不能为了让错误类型的卡牌
通过编译而添加入场曲。类型决定卡牌是否占用战场、结算后的区域及是否触发魔力增幅，
这些行为需要通过编译后卡牌的对局测试验证。

文本中的“战场上的所有随从”使用 `field.followers` 在同一次操作中结算，
不能拆成己方和对手两个操作，以免改变死亡批次与谢幕曲的执行顺序。

导入脚本导入卡牌身份、种族、费用、身材和多语言文本，并生成可被检查器读取的 WBO 卡牌骨架。
未知卡牌类型或种族编号会使导入报错，不会默认成法术或无种族。已存在的卡牌文件会被跳过，
不会覆盖已编写的效果。脚本不会把素材文件复制进规则包，也不会把文本自动解释成规则动作；
规则作者需要根据权威文本补全 `effect`、触发器和测试场景。

新增规则应同时提供：

- 与来源文本对应的卡牌或关键词定义；
- 覆盖正常、边界和冲突结算的 `.wbotest` 场景；
- 对未确定语义的显式诊断或 `unsupported_feature` 结果。
